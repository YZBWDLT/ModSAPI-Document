ItemStack

作用域：服务端。

源码：core_behavior/ModSAPI/modules/server/ItemStack.py；声明补充了静态类型信息。

一组同类物品的堆叠。

获取方式​

从服务端入口导入 ItemStack，或从容器读取物品副本。

字段与常量​

名称类型线索默认值 / 来源说明
keepOnDeath由运行时值确定``
lockMode由运行时值确定``

字段显示为源码赋值来源时，该表达式不是调用者应直接执行的初始化代码。常量值以当前 Python 实现为准。

构造器​

ItemStack(itemType: str, amount: int = 1, data: dict = None) -> None

构造该类型。通常通过下方获取方式使用；需要引擎上下文的包装器不建议自行构造。

参数​

名称类型线索默认值说明
itemTypestr必填传给 ItemStack.init 的 itemType 参数；结合上方功能说明和下方调用示例使用。
amountint1物品数量；新物品要求 1–255 的整数，并按最大堆叠数限制。
datadictNone传入的数据。跨端通信必须可传输；创建选项需符合该类型的数据结构。

返回类型： None。静态声明不替代本页的实现限制。

显式异常​

异常校验信息 / 条件线索
ValueError'Invalid item type: %r' % (itemType,)
ValueError'Unknown item type: %s' % self.__typeId

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。

原生调用： GetItemBasicInfo, GetLevelId。
