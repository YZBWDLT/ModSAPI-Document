构造器​

World(namespace, systemName)

构造该类型。通常通过下方获取方式使用；需要引擎上下文的包装器不建议自行构造。

参数​

名称类型线索默认值说明
namespace由值/所属选项确定必填本功能独有的命名空间，避免与其他功能的持久化数据冲突。
systemName由值/所属选项确定必填传给 World.init 的 systemName 参数；结合上方功能说明和下方调用示例使用。

返回值： 当前实现不显式返回结果，Python 返回 None。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。

getStorage​

getStorage(namespace: str) -> KeyValueStorage

返回按命名空间隔离的持久化 JSON 存储，属于网易扩展。命名空间应标识所属模组；数据存于保留的世界 ExtraData 键，每次成功写入均保存。数据不合法时抛出 TypeError 或 ValueError，原生失败时抛出 NativeOperationError。与客户端存储不共享数据。

当前实现说明

网易扩展。与客户端存储不共享；每个命名空间为独立 JSON 文档。

参数​

名称类型线索默认值说明
namespacestr必填本功能独有的命名空间，避免与其他功能的持久化数据冲突。

返回类型： KeyValueStorage。静态声明不替代本页的实现限制。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。

原生调用： GetExtraData, SetExtraData。
