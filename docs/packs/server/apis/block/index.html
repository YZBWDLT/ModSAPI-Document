Block

作用域：服务端。

源码：core_behavior/ModSAPI/modules/server/Block.py；声明补充了静态类型信息。

维度内某个坐标上的方块包装对象。由维度和唯一的 x、y、z 坐标定位，可读取和设置该位置的方块状态。

获取方式​

使用 dimension.getBlock(location)；这是位置包装器，不是不可变方块快照。
