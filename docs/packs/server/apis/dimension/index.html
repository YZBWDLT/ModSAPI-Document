Dimension

作用域：服务端。

源码：core_behavior/ModSAPI/modules/server/Dimension.py；声明补充了静态类型信息。

世界中的特定维度，例如末地。

获取方式​

使用 world.getDimension("overworld") 等；对象的维度也可从实体或方块读取。
