构造器​

WorldAfterEvents(owner = None)

构造该类型。通常通过下方获取方式使用；需要引擎上下文的包装器不建议自行构造。

参数​

名称类型线索默认值说明
owner由值/所属选项确定None传给 WorldAfterEvents.init 的 owner 参数；结合上方功能说明和下方调用示例使用。

返回值： 当前实现不显式返回结果，Python 返回 None。
