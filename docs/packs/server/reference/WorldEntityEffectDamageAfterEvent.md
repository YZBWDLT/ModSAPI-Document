# WorldEntityEffectDamageAfterEvent

作用域：服务端。

源码：`core_behavior/ModSAPI/modules/server/NativeEventTypes.py`；声明补充了静态类型信息。

此类型由运行时事件契约创建，并通过对应端的 `beta` 导出。通过 `subscribe` 回调取得实例；不要自行构造事件参数。

[EntityEffectDamageServerEvent](../native-events.md#entityeffectdamageserverevent) 的事件参数；同步分发结束后不能再写入输出字段。

## 获取方式

通过下方所属信号的回调参数取得；类型可从对应端 beta 导入，用于识别事件类型。

所属信号：[world.afterEvents.entityEffectDamage](../events/afterEvents.md#entityEffectDamage).

基类：[NativeEventData](../../common/reference/NativeEventData.md).

## 使用示例


```python

    print(event)

world.afterEvents.entityEffectDamage.subscribe(on_event)

def cleanup():
    world.afterEvents.entityEffectDamage.unsubscribe(on_event)
```
