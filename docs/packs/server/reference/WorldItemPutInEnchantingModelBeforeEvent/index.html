WorldItemPutInEnchantingModelBeforeEvent

作用域：服务端。

源码：core_behavior/ModSAPI/modules/server/NativeEventTypes.py；声明补充了静态类型信息。

此类型由运行时事件契约创建，并通过对应端的 beta 导出。通过 subscribe 回调取得实例；不要自行构造事件参数。

OnItemPutInEnchantingModelServerEvent 的事件参数；同步分发结束后不能再写入输出字段。

获取方式​

通过下方所属信号的回调参数取得；类型可从对应端 beta 导入，用于识别事件类型。

所属信号：world.beforeEvents.itemPutInEnchantingModel.

基类：NativeEventData.

player: Optional[Player]

数据来源为原生字段 playerId；只读。字段缺失时返回 None。公开类型及对象包装以本成员的返回类型为准。

当前实现说明

玩家id，参数类型为str；只读。

访问： 只读。

返回类型： Optional[Player]。静态声明不替代本页的实现限制。

附魔台选项；此字段可在同步回调中赋值。
