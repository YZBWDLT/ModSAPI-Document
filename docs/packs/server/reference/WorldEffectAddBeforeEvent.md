# WorldEffectAddBeforeEvent

作用域：服务端。

源码：`core_behavior/ModSAPI/modules/server/NativeEventTypes.py`；声明补充了静态类型信息。

此类型由运行时事件契约创建，并通过对应端的 `beta` 导出。通过 `subscribe` 回调取得实例；不要自行构造事件参数。

[WillAddEffectServerEvent](../native-events.md#willaddeffectserverevent) 的事件参数；同步分发结束后不能再写入输出字段。

## 获取方式

通过下方所属信号的回调参数取得；类型可从对应端 beta 导入，用于识别事件类型。

所属信号：[world.beforeEvents.effectAdd](../events/beforeEvents.md#effectAdd).

基类：[NativeEventData](../../common/reference/NativeEventData.md).

## 使用示例


```python
from ModSAPI.server.beta import world

def on_event(event):
    print(event)

world.beforeEvents.effectAdd.subscribe(on_event)

def cleanup():
    world.beforeEvents.effectAdd.unsubscribe(on_event)
```
