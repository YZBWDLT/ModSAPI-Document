类型说明
Block维度内某个坐标上的方块包装对象。由维度和唯一的 x、y、z 坐标定位，可读取和设置该位置的方块状态。
BlockComponent方块组件的基类。
BlockEvent影响特定方块的事件信息。
BlockExplodeAfterEvent投射物命中方块的事件信息。

BlockInventoryComponent世界中方块的库存，例如箱子的容器。
BlockPermutation描述方块的 BlockType 与属性组合，属性也称方块状态。此对象不绑定到世界中的具体 Block。
BlockType方块的类型或模板；除类型标识外，不包含具体状态组合数据。
BlockVolume以两个角点描述世界中的三维方块区域。两个角点的分量不要求按最小值、最大值排序，且始终保留初始角点身份；编辑时即使两角点交叉，也不会交换它们的含义。角点不能直接当作已排序的方块位置范围；需要边界范围时使用 getBoundingBox。区域按方块计数并包含端点，因此从 (0, 0, 0) 到 (0, 0, 0) 的区域大小为 (1, 1, 1)。
