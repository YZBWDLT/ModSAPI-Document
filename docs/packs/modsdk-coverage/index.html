目前不能确认本库已覆盖绝大多数 ModSDK 功能。 名称匹配只用于定位候选调用；已有离线核验路径也只证明列出的功能子集，不表示支持原生接口的全部参数、平台或游戏时序。

常用界面流程见 界面、控件与生命周期、主题表单、选择控件与小地图 和 模型预览与图片适配。模型高级挂接、专有渲染和平台能力仍有大量接口待适配。使用 native 访问原生对象，不会自动使这些能力成为本库已实现的接口。
