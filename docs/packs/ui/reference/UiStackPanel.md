# UiStackPanel

作用域：界面、控件和两端组合表单。

源码：`core_behavior/ModSAPI/ui/widgets.py`；声明补充了静态类型信息。

原生堆叠布局，按水平或垂直方向排列子控件。

## 获取方式

使用 view.getControl(path, "stackPanel")。

基类：[UiControl](UiControl.md).

## orientation {#orientation}

```python
orientation: Literal['horizontal', 'vertical']
```

排列方向：horizontal 表示水平，vertical 表示垂直。

**访问：** 可读写。

写入方式：`instance.orientation = value`。参数类型线索：`(value: Literal['horizontal', 'vertical']) -> None`。

写入参数 `value`：[Literal](../../common/type-system.md#literal)['horizontal', 'vertical']。

**返回类型：** [Literal](../../common/type-system.md#literal)['horizontal', 'vertical']。静态声明不替代本页的实现限制。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。
