UiService

作用域：界面、控件和两端组合表单。

源码：core_behavior/ModSAPI/ui/service.py；声明补充了静态类型信息。

管理本地视图以及组合表单、状态工厂。原生视图在客户端操作；服务端创建表单并向玩家对象显示，不能直接读取远端原生界面树。

获取方式​

通过 client.ui 或 system.ui 获取。原生视图方法只在客户端可用。

registerView​

registerView(name: str, template: str, options: UiViewCallbacks | None = None) -> UiViewDefinition

声明界面模板，可提供就绪、更新和关闭回调。初始化前可以声明；原生界面就绪后首次打开时执行一次登记。

参数​

名称类型线索默认值说明
namestr必填传给 UiService.registerView 的 name 参数；结合上方功能说明和下方调用示例使用。
templatestr必填传给 UiService.registerView 的 template 参数；结合上方功能说明和下方调用示例使用。
optionsUiViewCallbacks | NoneNone附加选项字典。字段及默认值见本页选项与关联类型；未实现字段不会因此生效。

返回类型： UiViewDefinition。静态声明不替代本页的实现限制。
