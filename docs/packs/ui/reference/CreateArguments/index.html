CreateArguments

作用域：界面、控件和两端组合表单。

源码：core_behavior/ModSAPI/_ui/core/utils/type.py；声明补充了静态类型信息。

获取方式​

通过客户端自定义控件的 onCreate 回调取得。

成员索引​

名称形态
screenNode只读属性
control只读属性
params只读属性
style只读属性

screenNode​

screenNode: ScreenNode

读取 screenNode 的当前值。

访问： 只读。

返回类型： ScreenNode。静态声明不替代本页的实现限制。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。
