# UiInputPanel

作用域：界面、控件和两端组合表单。

源码：`core_behavior/ModSAPI/ui/widgets.py`；声明补充了静态类型信息。

原生输入面板，支持模态、输入拦截和拖拽偏移设置。

## 获取方式

使用 view.getControl(path, "inputPanel")。

基类：[UiControl](UiControl.md).
