UiControl

作用域：界面、控件和两端组合表单。

源码：core_behavior/ModSAPI/ui/controls.py；声明补充了静态类型信息。

由视图拥有的原生控件；原生操作要求所属视图存活且已经就绪。

获取方式​

由 UiView.getControl、UiView.createControl 或 UiControl.getChild 返回。
