# UiToggle

作用域：界面、控件和两端组合表单。

源码：`core_behavior/ModSAPI/ui/controls.py`；声明补充了静态类型信息。

使用编辑器模板中 this_toggle 子节点的开关控件。

## 获取方式

使用 view.getControl(path, "toggle")。

## value {#value}

```python
value: bool
```

读取 `value` 的当前值。

**访问：** 可读写。

写入方式：`instance.value = value`。参数类型线索：`(value: bool) -> None`。

写入参数 `value`：[bool](../../common/type-system.md#bool)。

**返回类型：** [bool](../../common/type-system.md#bool)。静态声明不替代本页的实现限制。
