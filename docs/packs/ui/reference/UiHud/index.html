UiHud

作用域：界面、控件和两端组合表单。

源码：core_behavior/ModSAPI/ui/display.py；声明补充了静态类型信息。

由有效本机界面服务持有的原生抬头显示写入入口。调用需要界面就绪。原生接口没有显隐读取，因此不能恢复未知旧状态、推断真实可见性或隔离其他模组；客户端退出时不会隐式全局重置。

获取方式​

从 client.ui.hud 取得本地原生抬头显示控制句柄；实际调用需要界面就绪。

setHudVisibility​

setHudVisibility(visibility: int, hudElements: list[str] | tuple[str, ...] | None = None) -> None

隐藏或恢复 UiHudElement 的指定原生抬头显示通道，使用 HudVisibility 的 Hide 或 Reset。省略元素时操作全部二十二个受支持通道，空序列不写入。写入前检查全部参数和方法是否存在；重复通道按首次出现顺序处理一次。后续原生失败可能保留先前修改，没有显隐快照用于回滚。

当前实现说明

省略元素时操作全部二十二个已支持通道；空列表不写入。先校验整批参数与方法是否存在，但不提供失败回滚或跨模组隔离。

参数​

名称类型线索默认值说明
visibilityint必填传给 UiHud.setHudVisibility 的 visibility 参数；结合上方功能说明和下方调用示例使用。
hudElementslist[str] | tuple[str, ...] | NoneNone传给 UiHud.setHudVisibility 的 hudElements 参数；结合上方功能说明和下方调用示例使用。

返回类型： None。静态声明不替代本页的实现限制。

setHidden​

setHidden(hidden: bool) -> None

应用类似 F1 的全局抬头显示隐藏；隐藏位置仍可能响应触控。此入口操作全局开关，传入 False 时释放该开关，不会逐项调用元素重置。

当前实现说明

类似 F1 的全局隐藏，原位置可能继续响应输入；不会逐项调用元素重置。输入限制请使用 client.input。

setChatPosition​

setChatPosition(position: Vector2 | tuple[float, float] | list[float] | dict[str, float]) -> None

以有限的二维坐标移动抬头显示中的小消息窗口。原点在玩家纸娃娃下方，不是物理窗口原点；保留负坐标和零值。此原生接口不提供位置读取或自动恢复。

参数​

名称类型线索默认值说明
positionVector2 | tuple[float, float] | list[float] | dict[str, float]必填位置或坐标；采用本接口所属的原生坐标约定。

返回类型： None。静态声明不替代本页的实现限制。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。
