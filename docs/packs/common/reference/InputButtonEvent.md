# InputButtonEvent

作用域：公共数据、选项、枚举与错误。

源码：`core_behavior/ModSAPI/utils/event_data.py`；声明补充了静态类型信息。

[InputButtonEvent](InputButtonEvent.md) 类型的语义事件参数。可通过 nativeEvent 读取原生详情；对象引用按需创建，容器值均为独立副本。

## 获取方式

通过下方所属信号的回调参数取得；类型可从对应端 beta 导入，用于识别事件类型。

所属信号：[client.afterEvents.inputButton](../../client/reference/ClientAfterEvents.md#inputButton).

```python

```

**返回类型：** [str](../type-system.md#str)。静态声明不替代本页的实现限制。

## 使用示例


```python
from ModSAPI.client.beta import client

def on_event(event):
    print(event)

def cleanup():
    client.afterEvents.inputButton.unsubscribe(on_event)
```
