clearData​

clearData(keys = None)

清除本数据库写入的键；对于旧数据，需要显式传入键列表。保留未被跟踪的世界 ExtraData。原生写入不具备事务性；失败会报告错误，可重试清除。

参数​

名称类型线索默认值说明
keys由值/所属选项确定None传给 ManagedStorage.clearData 的 keys 参数；结合上方功能说明和下方调用示例使用。

返回值： 当前实现不显式返回结果，Python 返回 None。
