ClientBeforeEvents

作用域：客户端。

源码：core_behavior/ModSAPI/modules/client/ClientEvents.py；声明补充了静态类型信息。

待执行操作和原生输出变化的客户端同步钩子。只能修改开发包明确标记为可写的字段，且必须在回调内完成。部分操作需要客户端和服务端共同取消，具体见事件目录。此处不实现微软的受限执行阶段。

获取方式​

从 client.beforeEvents 获取。

按准确原生名称返回缓存的信号。名称未知、执行端或钩子阶段不符时抛出 KeyError；名称参数不合法时抛出 TypeError 或 ValueError；对象已释放时抛出 InvalidClientObjectError。引擎和平台的前置条件仍然适用。

参数​

名称类型线索默认值说明
eventNamestr必填事件或请求名称，推荐加入自己的命名空间。

返回类型： NativeEventSignal[NativeEventData]。静态声明不替代本页的实现限制。
