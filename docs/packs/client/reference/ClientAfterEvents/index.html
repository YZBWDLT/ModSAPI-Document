构造器​

ClientAfterEvents(clientSystem)

构造该类型。通常通过下方获取方式使用；需要引擎上下文的包装器不建议自行构造。

参数​

名称类型线索默认值说明
clientSystem由值/所属选项确定必填传给 ClientAfterEvents.init 的 clientSystem 参数；结合上方功能说明和下方调用示例使用。

返回值： 当前实现不显式返回结果，Python 返回 None。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。
