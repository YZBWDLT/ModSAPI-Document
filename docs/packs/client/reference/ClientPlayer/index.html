ClientPlayer

作用域：客户端。

源码：core_behavior/ModSAPI/modules/client/Player.py；声明补充了静态类型信息。

本地玩家的可读状态及本地显示控制。

获取方式​

使用 client.localPlayer。

基类：ClientEntity.

setVelocity​

setVelocity(velocity: VectorLike) -> None

使用有限的世界向量替换本地玩家的原生运动，不是叠加冲量。频繁写入可能与服务端模拟不一致；权威移动应在服务端完成。其他客户端实体没有此写入方法。

参数​

名称类型线索默认值说明
velocityVectorLike必填传给 ClientPlayer.setVelocity 的 velocity 参数；结合上方功能说明和下方调用示例使用。

引擎调用、失效对象或下层校验仍可能抛出其他异常；这里只列出当前成员内显式写出的错误。
