ClientEntity

作用域：客户端。

源码：core_behavior/ModSAPI/modules/client/Entity.py；声明补充了静态类型信息。

客户端可见实体的包装对象；仅允许移除由本地创建的实体。

获取方式​

使用 client.getEntity(id) 或 client.spawnEntity(...)。

getComponent​

getComponent(componentId: str) -> ClientEntityAttributeComponent | ClientEntityInventoryComponent | ClientEntityEquippableComponent | None

取得已支持的只读组件；受支持属性不存在时返回 None。生命和陆地、水中、岩浆移动速度读取已同步属性；背包和装备组件当前仅支持本地玩家。其他标识符及不能访问的远端背包抛出 UnsupportedFeatureError，不会伪装成原生行为组件不存在。

当前实现说明

已支持四种同步属性；本地玩家另支持 inventory 和 equippable。其他实体的背包与装备当前不由这两个客户端组件提供，会抛出 UnsupportedFeatureError，不能把不支持的范围当作不存在。

teleport​

teleport(location: Vector3 | dict[str, float] | tuple[float, float, float]) -> None

移动 client.spawnEntity 创建的本地实体，不移动服务端实体。保留原生位置约定；本地玩家传送和跨维度移动应使用服务端操作。

当前实现说明

仅修改 client.spawnEntity 返回的本地实体；其他句柄抛出 UnsupportedFeatureError。原生位置约定保持不变，不提供服务端或跨维度传送。
