官方对照与当前支持情况

比较基准为微软稳定版 server 2.11.0 / server-ui 2.3.0。此页记录结构对照，不以名称存在、字典结构或枚举常量来宣称功能已经完整实现。客户端模块是网易扩展。

状态：未实现 = 当前没有对应运行时类型；结构契约 = 参数/数据形状；部分 = 存在缺失或显式拒绝；待行为核验 = 名称和成员存在，仍需核验原生语义。

@minecraft/server 2.11.0​

微软模块文档

已知限制​

  • ScreenDisplay/native HUD parity：本地网易原生 HUD、原版界面请求及几何读取已通过 client.ui 封装；没有可验证的原生 HUD 显隐读取、未知旧值恢复和完整微软 HudElement 对应，未冒充服务端 ScreenDisplay 的完整实现。
  • Container/specialized block inventories：个人末影箱已通过 Player.enderChest 统一封装；熔炉、高炉、烟熏炉及酿造台还缺少完整全槽与元数据适配，明确拒绝通用箱子后端，不能将专用接口无结果当作空槽。
  • Container/transient UI inventories：合成界面及网易共享临时槽位依赖原生界面上下文、特殊槽位限制及 needBack 回退规则，尚未包装为普通容器。
  • ItemEnchantableComponent/native parity：按网易 primary_slots 和 incompatible 校验，批量预检后才改动；未知原生编号保留但不能猜测新增兼容性。次级槽位、原版附魔差异及实际作用仍需实机核验。
  • ItemDurabilityComponent/unbreakable and damage chance：当前支持损耗和剩余耐久编辑及原生变种上限；不损坏状态、耐久损耗概率范围与耐久附魔算法没有可靠原生等价映射，尚未伪造实现。
  • Container/native transactions：批量读取与多槽写入不是原生事务。失败会尝试恢复并读回；无法确认恢复时报告 ContainerRollbackError，不能保证跨模组隔离。
  • Container.containerRules/weight：网易容量和物品读写不能直接提供微软容器规则、嵌套重量及虚拟容器的等价语义，当前不伪造结果。
  • ItemStack.setLore RawMessage：当前支持普通文本及字符数量校验，getRawLore 返回 text 记录；完整 RawMessage 写入尚未适配。
  • ItemStack/dynamic property persistence：使用独立版本化原生标签，保留外部 extraId；载荷最多三万二千七百六十七个 UTF-8 字节，含格式开销。实机保存、跨版本和第三方处理链仍待核验。
  • ItemStack.getDynamicPropertyTotalByteCount：尚未取得微软原生动态属性物理存储大小的等价计量，不能用适配器 JSON 长度冒充。
  • EntityAttributeComponent.effectiveMin：当前读取属性 NBT 的 Min；尚未证明额外最小值修饰因素与微软有效最小值完全等价。
  • EntityAttributeComponent/modifier persistence：原生五项修饰器接口已封装；没有证据表明修饰器跨存档或重载持久化，不能将 ModAttr.SaveAttr 冒充修饰器保存。叠加次序、上限运算和最小值修饰器影响仍待实测。
  • EntityAttributeComponent.resetToMaxValue：使用原生重置；未显式设置过的无穷上限按网易规则恢复默认值，不能宣称所有无穷边界行为与微软运行时一致。
  • EntityEquippableComponent.getEquipment/setEquipment Body：网易 ArmorSlotType.BODY 是胸甲槽，不是 SAPI 的 Body 槽；尚无经核验的 Body 映射，当前明确拒绝。
  • Player.playSound：仅向指定在线玩家播放一次并上报失败；loopCount 非零会明确拒绝，当前后端不能返回新版 SoundInstance 句柄。
  • Player.camera：服务端仍为空返回；网易客户端摄像机与 SAPI 相机预设/栈/缓动/瞄准并非同一接口，需逐项适配。
  • Player.clientSystemInfo：现有同步属性为空返回；网易客户端数据只能通过通信获得，尚未建立可靠缓存。
  • World.getLootTableManager：现有空返回；需先核实网易对战利品表读取、上下文和随机生成的支持。
  • DataDrivenEntityTriggerAfterEvent.getModifiers：现有空实现；未取得与微软组件组修改器同等的事件上下文。
  • PrimitiveShapesManager.addText：现有空实现；需补充服务端到客户端的文字绘制生命周期和玩家范围管理。
  • PrimitiveShapesManager.removeText：依赖尚未实现的文字实例管理。
  • PrimitiveShapesManager.removeAll：现有空实现，不能据此声称已清理绘制对象。
  • Block.getItemStack(withData=True)：网易接口未提供无损方块实体到物品的序列化；目前只支持不带数据的类型转换。
  • BlockPermutation.getItemStack：现有原型物品转换只保留类型和数量，尚未核实方块状态到物品 aux 的完整映射；不能保证保留颜色等变种。
  • Dimension/block native parity：新增过滤、稀疏体积及未加载区块分支已通过离线回归；高度越界、方块实体更新和实际区块加载竞态仍需网易实机核验。
  • GameRules/*missing：GetGameRulesInfoServer 仅提供部分规则；仅实现了已核实的 18 项读写，不能用本地缓存伪装其他原生规则。
  • System.currentTick：网易脚本更新为每秒 30 次，当前计时器适配为 20 ticks/s；尚未统一暂停/卡顿下的刻计数语义。
  • World.clearDynamicProperties：现有动态属性与其他模组共享 ExtraData 命名空间；缺少完整的旧数据所有权索引，直接全删会影响其他模组。
  • Dimension.cloneBlocks：需正确处理目标重叠、过滤、容器/方块实体、实体和未加载区域；现有调色板复制不足以证明等价。
  • native component registries：微软运行时自定义方块/物品组件注册与网易 JSON 定义、事件系统不同，尚未建立完整生命周期映射。
  • native-only modern engine features：AimAssist、LocatorBar/Waypoint、FogSettings、物品书/容器规则/动态方块属性等需对应网易能力，缺少实现不能直接认定可完整模拟。

@minecraft/server-ui 2.3.0​

微软模块文档

已知限制​

  • CustomForm.image：网易 JSON UI 以全局贴图路径查找资源，当前适配器无法按官方 pack 标识解析并隔离贴图；动态图也未核实。
  • ObservableString.getFilteredText：未找到按玩家调用微软文本过滤服务的网易接口；不能把未过滤原文冒充过滤结果。
  • *.translate：未找到可供当前 JSON UI 适配器调用的本地化键解析接口；目前仅支持 text/rawtext 的字面文本。
  • *.tooltip：已保留参数；悬浮提示和移动端呈现尚未接入，不能视为已经支持。
  • *.description：已保留动态参数；描述文字布局尚未接入。
  • ModalFormData.textField.placeholderText：参数已保存，客户端占位符布局尚未接入。
  • UserBusy/native：当前检测本库正在显示的表单；原生聊天/背包/第三方 UI 的忙碌状态和打开失败需客户端握手，尚未实现。
  • CustomForm/native DDUI：网易侧使用 JSON UI 渲染，不能提供微软 DDUI 原生外观、引擎错误和限制执行阶段的完全等价行为。
  • CustomForm.dropdown/dynamic items：当前实现会重建变化的下拉项目并复用未变化节点；真实客户端布局和更新时序仍需实机验证。
  • *.RawMessage(score/selector)：当前 JSON UI 只接受字面 text/rawtext；score/selector 解析及依赖玩家上下文的格式尚未接入。
