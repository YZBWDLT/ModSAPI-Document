快速建造 Editor

《快速建造 Editor》是一款面向 Minecraft Bedrock 的游戏内建造编辑器。无需离开世界，即可完成选区编辑、结构处理、几何画笔、任意旋转和历史回退。

模组亮点​

电脑快捷键​

编辑器支持原生键位映射，并归类在 MCEditor 设置中，玩家可以按自己的习惯改键。默认按下 M 打开编辑器，常用工具可以使用数字键、字母键、方向键和功能键快速调用。

完整时间线​

选择、填充、删除、剪切、移动、旋转、粘贴和画笔操作都会记录到时间线。玩家可以撤销、重做，按时间查看历史状态，并返回某个已保存的操作状态。

多功能选区​

支持包含空气和不包含空气两种选择方式，支持重新选择点 A、点 B 或整个范围。切换选择模式时，已有选区范围可以保留，同时重新计算选中的方块数据。

几何与自定义画笔​

画笔支持球体、方体、柱体、棱锥、自定义结构和闭合多边形底面。画笔可以设置尺寸、旋转、空心大小、画笔间距和统一尺寸；空心尺寸为 0 时生成实心形状。

正常模式使用玩家手中的方块，删除模式使用黑色或灰色玻璃预览移除范围。自由绘画支持逐笔撤销，连线模式可以在两点之间生成连续画笔。

结构导入与导出​

选区可以导出为结构或画笔，之后从库中搜索并导入。粘贴预览支持移动、旋转、镜像和缩放，确认后再提交到世界。

预览与安全操作​

编辑结果会先以纸娃娃或玻璃方块预览，原位置的方块纹理会暂时隐藏。大多数操作都由服务端验证和执行，提交前可以检查范围，完成后可以从时间线撤销。

快速开始​

  1. 在世界中按 M，或点击屏幕上的编辑器入口。
  2. 使用“选择”工具点击两个方块，建立选区。
  3. 从左侧选择填充、删除、画笔、旋转、贝塞尔或粘贴工具。
  4. 在右侧调整参数，观察预览结果。
  5. 点击提交按钮，将操作应用到世界。
  6. 需要回退时，使用顶部撤销按钮或时间线。
